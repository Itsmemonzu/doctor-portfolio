# Doctor portfolio

A single-page portfolio for a New York neurologist: who they are, what they treat, where they practise, their training, and every contact and social link in one place. Static HTML and CSS, no build step.

**This is a placeholder profile.** The name, photo, credentials, offices, phone numbers and social links are examples to replace with the real doctor's details.

## Run locally

```bash
python -m http.server 5191
```

Then open http://localhost:5191.
